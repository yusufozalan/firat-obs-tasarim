
# Fırat Üniversitesi OBS Giriş Ekranı Tasarımı

Bu proje, Fırat Üniversitesi Öğrenci Bilgi Sistemi (OBS) giriş ekranı için geliştirilmiş alternatif, modern ve responsive (mobil uyumlu) bir front-end arayüz çalışmasıdır.

## Özellikler
* **Kurumsal Kimlik:** Üniversitenin resmi bordo renk kodu (`#701036`) ve logoları kullanılarak marka bütünlüğü sağlandı.
* **Göz Yormayan Tasarım:** Parlak beyaz zeminler yerine mat ve soft gri tonlar tercih edilerek UI/UX iyileştirmesi yapıldı.
* **Mobil Uyumlu (Responsive):** Media queries kullanılarak mobil cihazlarda sağ panel gizlendi ve dikey ekran optimizasyonu yapıldı.
